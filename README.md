# Wireshark Network Traffic Analysis Project

## 📌 Overview
This project demonstrates network traffic capture and analysis using Wireshark on Kali Linux. The goal is to understand packet-level communication and basic protocol behavior.

## 🛠 Tools Used
- Kali Linux
- Wireshark
- Git & GitHub

## 📂 Project Files
- capture1.pcapng → Network traffic capture file
- traffic_analyzer.sh → Basic analysis script
- notes.txt → Observations and findings

## 📊 Key Learning Outcomes
- Capturing live network packets
- Understanding TCP, DNS, and HTTP traffic
- Using Wireshark filters effectively
- Saving and analyzing `.pcapng` files
- Using GitHub for version control

## 🔍 Wireshark Filters Used
- http
- dns
- tcp

## 🚀 How to Use
1. Open Wireshark
2. Load `capture1.pcapng`
3. Apply filters to analyze traffic
